SAMPSA JEPPEZ — V09 / RECHERCHES SUR TABLE

Une seule référence modifiée : 11.
Les 12 autres images sont reprises à l'identique de la V08. Les anciennes versions restent intactes.

RÉFÉRENCE 11 FINALE
Riz soulève une feuille pour la lire. Le dos de cette feuille, tourné vers la caméra, est vierge.
Les sculptures de bougies à gauche, à droite et au centre sont supprimées.
Une vingtaine de feuilles de recherche superposées et réparties en piles couvre la table. Les pages posées à plat gardent leurs graphiques illustratifs. Sampsa pointe l'un d'eux.
Le titre « $1+ Million in One Trade », le décor aubergine, les couleurs, les expressions et les zones centrales vérifiées des visages sont conservés.

LIVRAISON
Galerie.html : filtre initial sur la référence 11, comparaison V08/V09, bouton Tout pour les 13 images, téléchargements individuels.
exports_4K : 13 PNG 3840 × 2160. Seul le PNG 11 est nouveau.
masters : 13 images 1672 × 941 avant le grain final.
apercus : aperçus 1280 px et 320 px, planches et versions V08 pour comparaison.
sources_HD : photos originales de référence.
production : prompts, générations intermédiaires, assemblage, contrôles et traçabilité.

Les PNG sont agrandis depuis les masters 1672 × 941 ; ce ne sont pas des créations natives 4K.
Grain monochrome uniforme ±4 % appliqué une seule fois à l'export. Les douze exports repris ne reçoivent aucun grain supplémentaire.

PRODUCTION
Outil intégré image_gen.imagegen, puis assemblage local des régions modifiées sur la version approuvée.
Generation_job.json contient la première demande avec deux bougies. Correction_job.json contient la dernière correction du client : retirer les bougies et rendre vierge le dos de la feuille levée. Les intermédiaires restent archivés uniquement pour la traçabilité.
Le nom technique 11_Green est conservé pour correspondre aux versions précédentes ; le visuel final ne contient aucune sculpture de bougie.
Les quatre accroches anglaises sont celles fournies par le client ; aucune nouvelle affirmation de performance n'est ajoutée. Les schémas sont illustratifs.

CONTRÔLES
Dimensions, grain, préservation des zones centrales des deux visages, titre, identité binaire des douze exports repris, fichiers de la galerie, syntaxe JavaScript et intégrité SHA256 du ZIP vérifiés.
Le test interactif de la galerie n'est pas déclaré : l'outil navigateur bloque le protocole local file:.
Archive : Sampsa_Jeppez_V09_13_Thumbnails_4K.zip dans le dossier parent. Après extraction, la galerie et les téléchargements d'images restent autonomes ; le bouton ZIP suppose que l'archive reste dans le dossier parent.
