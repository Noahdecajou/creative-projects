SAMPSA JEPPEZ — V06 AUBERGINE BRANDING

28 miniatures basées sur les 28 compositions de V05_Natural_Set.
Ouvrir Galerie.html : comparaison V05/V06, vue mobile à 320 px,
variantes solo/duo et comparaison des deux bougies de la référence 11.

BRANDING
Aubergine de référence : #511F58, intégré aux murs, ombres et matières
des décors. La photographie conserve naturellement des nuances.
Jaune de référence : #FFEC04, mots clés noirs dans un encadré lumineux.
Les autres mots restent blancs. Éclairage chaud du décor et teintes
de peau préservées pour séparer les visages du fond.

LIVRAISON
exports_4K/ : 28 PNG individuels 3840 × 2160, format 16:9.
masters/ : 28 masters assemblés 1672 × 941 sans nouveau grain d'export.
apercus/ : versions 1280 px et 320 px, planches et comparatifs V05.
sources_HD/ : 29 images sources héritées du projet, intactes.
references/ : planche Option B fournie pour le branding.
production/ : prompts complets, sorties brutes, scripts d'assemblage,
suivi des titres et rapports de vérification.

Les exports 3840 × 2160 sont AGRANDIS, et non créés nativement en 4K.
Redimensionnement bicubique depuis 1672 × 941 avec ajustement minimal
du cadrage vertical pour le 16:9 exact. Aucun ajout de netteté.
Un bruit monochrome uniforme de ±4 % de l'échelle 0–255 est ajouté
une seule fois aux exports, avec une graine fixe par référence.
Les textures déjà présentes dans les images sources sont conservées.

PRÉSERVATION
Les zones centrales des visages validés de V05 sont réintégrées par
masques avec raccord progressif. Les pixels de l'ancien fond cyan
sont exclus. Les zones centrales conservées sont vérifiées contre V05.
Les mains sélectionnées sont également réintégrées depuis V05.
Les décors, couleurs et encadrés ont été édités avec image_gen intégré,
puis les finitions d'assemblage, de texte et d'export sont déterministes.
Les photos HD originales restent disponibles pour toute autre retouche.

Les titres et leurs repères dans le transcript sont hérités de V05 et
répertoriés dans production/Suivi_titres.tsv. Aucun nouveau chiffre n'est
ajouté depuis la planche de branding. Les graphiques restent illustratifs.
Les noms Blur10/Blur15 identifient les deux compositions héritées de V05 ;
ils ne sont pas une nouvelle mesure du flou après l'édition du décor.

PROMPTS ET PROVENANCE
production/Generation_manifest.json contient les 28 prompts, les cibles
V05, la référence de style et les fichiers produits par l'outil intégré.
Les scripts conservent les chemins du projet local pour le réassemblage.
Les anciennes versions V03, V04 et V05 ne sont pas modifiées.
Aucune publication effectuée.
