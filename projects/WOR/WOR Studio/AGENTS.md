# WOR Studio — perimetre GitHub
Le seul depot autorise est https://github.com/Noahdecajou/wor-studio, prive.
Ne jamais exporter de conversations ChatGPT/Codex, historiques, memoires ou autres projets.
Ne pas suivre data/, dist/seed.js, les images utilisateur, rapports, feedbacks, logs, archives ou identifiants.
sync-allowlist.json contient la liste exacte des fichiers autorises. Tout ajout a cette liste exige une demande explicite de l'utilisateur.
Apres une modification terminee dans ce studio : verifier les fichiers, executer npm run check et Sync-WOR.ps1 avec un message descriptif. En cas de conflit, ne jamais forcer le push. Signaler un echec de synchronisation.
La synchronisation se fait en fin d'intervention ; aucun export global ni surveillance de dossiers externes.
